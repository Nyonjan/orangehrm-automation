# orangehrm-automation
Playwright automation testing project for OrangeHRM with POM, including login, employee management, and user administration.

## Overview

This project demonstrates the automation testing of the OrangeHRM web application using Playwright and the Page Object Model (POM) design pattern. It covers both manual and automated testing of core modules, including Login, Dashboard, Admin, and PIM. The automated test suite validates essential functionalities such as user authentication, employee management, employee search, and user administration while generating detailed execution reports to ensure application quality and reliability.
